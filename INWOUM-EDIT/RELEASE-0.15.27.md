# INWOUM EDIT 0.15.27

- แก้ HTTP 400 ในรอบซ่อมคำโดดของโหมดคลิปเดี่ยวแบบเรียบเรียง (Default / Default 02)
- ส่งเฉพาะบริเวณที่มีปัญหา พร้อมบริบทก่อนหลัง และคงแผนส่วนอื่นไว้ตามเดิม
- กำหนดรายการเหตุการณ์ครั้งเดียว ลดกฎรูปแบบคำตอบที่ซ้ำ โดยยังตรวจขอบคำ ท่อนที่ต้องเก็บ และลำดับเหตุการณ์ในเครื่อง
- ไม่เปลี่ยนรอบเรียบเรียงหลัก โหมดขายของ หรือ Original
- แยกข้อความ HTTP 400/401/403/429 ให้ตรงสาเหตุ โดยไม่แสดงข้อความลับจากบริการ
- ทดสอบในเครื่อง 468 tests ผ่าน และทดสอบสร้างคำขอจากงานที่เคยล้มโดยไม่เรียก API จริง
- งานเก่ายังคงอยู่ ไม่ย้ายหรือแก้ XML ของทีม อัปเดตแล้วกดทำต่อบนเครื่องต้นทางได้ โดยใช้คำตอบรอบแรกที่เก็บไว้
