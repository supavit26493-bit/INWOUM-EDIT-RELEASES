# INWOUM EDIT 0.15.29

- แก้โหมดขายของ 2.1 หยุดเมื่อเทคสำรองใช้ฟุตเทจเดียวกับเทคหลักทั้งหมด
- อนุญาตเทคสำรองที่ประกอบครบเป็นอีกมุมขายหรืออีกลำดับ ไม่บังคับว่าต้องมีข้อเท็จจริงหรือฟุตเทจใหม่ แต่ยังตรวจท่อนเปิด ประโยชน์ สาระ บริบท และราคาต้องห้าม
- สำเนาที่เหมือนคลิปหลักทั้งลำดับและช่วงคำยังถือว่าซ้ำ แม้แบ่งขอบ selection ต่างกัน
- เทคสำรองที่ยังไม่ผ่านจริง ๆ จะเก็บแผนและเหตุผลใน pending-reserves.json และแจ้งเตือน โดยไม่ขวางการส่งออกเทคหลักกับเทคสำรองอื่นที่ผ่าน ไม่ส่งซ้ำหรือเพิ่ม API อัตโนมัติ
- เทคหลักเดิมไม่ถูกแก้หรือลดจำนวน โหมดคลิปเดี่ยวและ Original ไม่เปลี่ยน
- ผ่าน 478 tests และทดสอบทำต่อจากสำเนางานที่ล้มจนส่งออก XML ครบ 4 เวอร์ชัน โดยบล็อกเครือข่ายและใช้คำตอบเดิมทั้งหมด
- รวมการอัปเดตก่อนหน้าครบ ให้ทีมอัปเดต เปิดโปรแกรมใหม่ เลือกงานเดิม แล้วกดทำต่อ ไม่ต้องถอดเสียงหรือวางแผนใหม่
