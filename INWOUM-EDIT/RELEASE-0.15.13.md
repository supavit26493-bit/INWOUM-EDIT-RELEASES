เพิ่มมาสคอต CAT · แมว, SLIME · นุ่มนิ่ม และ BOT · ผู้ช่วย ในเมนูมาสคอตด้านบน
ยังเลือกตัวกลมและสไลม์พิกเซลเดิมได้ จำตัวเลือกในเบราว์เซอร์
ตัวใหม่มองตามเมาส์ กระพริบตา ขยับเบา ๆ ขณะพัก เด้งขณะทำงาน และยิ้มเมื่องานเสร็จ
เปลี่ยนสีตามธีม อ่านสถานะเดิมของ NOOB/PRO/ซับ ไม่มีการเรียก API หรือใช้ token เพิ่ม
พักการวาดเมื่อแท็บถูกซ่อน มาสคอตอยู่นอกจอ หรือเลือกตัวเดิม รองรับการลดการเคลื่อนไหวของระบบ

เปลี่ยนเฉพาะหน้าตา ระบบตัดต่อ แทร็ก/ลิงก์ เสียง กฎ โมเดล API token/USD และคลัง Hook 2.2 คงเดิม
รวมอัปเดต 0.15.12 และก่อนหน้า ติดตั้งเฉพาะแพ็กนี้ได้
ตรวจตัวเลือกทั้งห้า NOOB/PRO การจำค่า การมองตามเมาส์ สถานะสำเร็จ/ผิดพลาด และทุกธีมแล้ว
ไม่เรียก API ทดสอบในรุ่นนี้ ไม่รันทดสอบ backend ซ้ำเพราะไฟล์ประมวลผลตรงกับ 0.15.12
ยังไม่ได้ทดสอบประสิทธิภาพเชิงตัวเลขหรือเครื่องใหม่
