# INWOUM EDIT 0.15.23

เพิ่มตัวเปิด INWOUMEDIT.exe พร้อมไอคอนโลโก้ Play ของโปรแกรม
ใส่ไอคอนเดียวกันบนหัวหน้าต่างและ Taskbar พร้อมแยกกลุ่มจาก Python

ต้องเก็บ INWOUMEDIT.exe ไว้กับไฟล์โปรแกรมเดิม ไม่ย้ายเฉพาะไฟล์ EXE ออกไป
เก็บ START-APP.cmd เป็นตัวเปิดสำรอง และ START-WEB.cmd / START.cmd สำหรับแบบเว็บ
คงพื้นที่บันทึกธีม API key งาน และระบบตัดต่อเดิม
ไม่มีค่า OpenAI API เพิ่ม

ตรวจ ICO หลายขนาดและไอคอนใน EXE ด้วย Windows แล้ว ตัวเปิดผ่านการตรวจพาธ และผ่าน 461 tests
