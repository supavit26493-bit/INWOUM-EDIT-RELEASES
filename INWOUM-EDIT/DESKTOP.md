# เปิดได้ทั้งแบบแอปและแบบเว็บ

- `INWOUMEDIT.exe` ตัวเปิดแอปพร้อมไอคอน ใช้เปิดตามปกติ
- `START-APP.cmd` ตัวเปิดแบบสำรอง
- `START-WEB.cmd` เปิดผ่านเบราว์เซอร์
- `START.cmd` เดิมยังเปิดแบบเว็บตามเดิม

ทั้งสองแบบใช้โฟลเดอร์งานและระบบตัดต่อเดียวกัน เปิดพร้อมกันได้โดยไม่เริ่มเซิร์ฟเวอร์ซ้ำ แต่ยังทำงานตัดต่อได้ครั้งละงานตามเดิม
ครั้งแรกของแบบแอปต้องเชื่อมอินเทอร์เน็ตเพื่อติดตั้งส่วนหน้าต่าง และต้องมี Microsoft Edge WebView2 Runtime
หากเปิดหน้าต่างไม่ได้ ใช้ START-WEB.cmd ต่อได้

ธีม มาสคอต และ API key ที่บันทึกในแอปใช้พื้นที่เก็บเฉพาะแอป แยกจากเบราว์เซอร์ จึงต้องใส่ key ในแอปครั้งแรก
ปิดหน้าต่างแอปแล้วงานที่กำลังทำยังทำต่อในเบื้องหลัง เปิดแอปหรือเว็บกลับมาดูงานได้
กดอัปเดตในแอปได้ หน้าต่างจะรอและเชื่อมกลับเมื่อระบบเปิดรุ่นใหม่ ไม่ต้องย้ายงาน
ไฟล์ XML และ SRT ดาวน์โหลดผ่านกล่องบันทึกไฟล์ของหน้าต่างแอป
