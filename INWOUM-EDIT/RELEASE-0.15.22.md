# INWOUM EDIT 0.15.22

เพิ่มการเปิดแบบแอปเดสก์ท็อปบน Windows ด้วย START-APP.cmd
เก็บแบบเว็บไว้ที่ START-WEB.cmd และ START.cmd เดิม
ทั้งสองแบบใช้ระบบตัดต่อและงานชุดเดียวกัน ป้องกันการเปิดเซิร์ฟเวอร์ซ้ำและตรวจว่าเชื่อมโฟลเดอร์โปรแกรมถูกตัว
เมื่อพอร์ตชนกับโปรแกรมอื่น จะเลือกพอร์ตว่างและจำตำแหน่งสำหรับการเปิดครั้งถัดไป
ปิดหน้าต่างแอปได้โดยไม่หยุดงานที่กำลังทำ เปิดกลับมาทำต่อหรือเปิดผ่านเว็บได้
หน้าต่างใช้ Microsoft Edge WebView2 รองรับดาวน์โหลด XML/SRT และเก็บธีมกับ API key ในโปรไฟล์แอปแยกจากเบราว์เซอร์
ครั้งแรกต้องใส่ API key ในแอปอีกครั้ง ไม่คัดลอก key จากเบราว์เซอร์อัตโนมัติ
ส่วนหน้าต่างติดตั้งเมื่อเปิดแอปครั้งแรก ไม่บังคับติดตั้งเพื่อเปิดแบบเว็บ
คงระบบตัดต่อเดิม กฎ โหมด ค่าเริ่มต้น และระบบอัปเดตจาก 0.15.21

ผ่าน 461 tests และทดสอบ backend จริง: เปิดซ้ำใช้ PID เดิม, แยกโปรแกรมเมื่อพอร์ตชน, ค้นพอร์ตใหม่ได้
ไม่มีการเรียก OpenAI หรือถอดเสียงเพื่อทดสอบรุ่นนี้

ตรวจหน้าต่างจริงบน Windows แล้ว: โหลด UI, เปิดงานเดิม, ดาวน์โหลด XML ตรงต้นฉบับทุกไบต์ และปิด/เปิดแอปโดยเซิร์ฟเวอร์เดิมยังอยู่
