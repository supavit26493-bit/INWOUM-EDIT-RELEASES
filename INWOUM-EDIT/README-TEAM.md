# INWOUM EDIT 0.14.0 สำหรับทีม

## เครื่องที่มีโปรแกรมอยู่แล้ว

ใช้ INWOUM-EDIT-0.13.6-UPDATE.zip แยกต่างหาก: ปิดโปรแกรมและหน้าต่าง START.cmd/เซิร์ฟเวอร์ก่อน แตก ZIP แล้วเปิด UPDATE.cmd เลือกโฟลเดอร์โปรแกรมเดิม รองรับ 0.12.4–0.13.6 ปิดแท็บเว็บอย่างเดียวไม่พอ

ตัวอัปเดตตรวจไฟล์และสำรองไฟล์ที่ทับไว้ใน backups/before-update-0.13.6-... ไม่แทนที่ jobs, .venv, โมเดล หรือ local-runtime.json ส่วน key ที่บันทึกในเบราว์เซอร์ยังอยู่ในเบราว์เซอร์เดิม

หากต้องย้อนกลับ ปิดโปรแกรมแล้วเปิด RESTORE.cmd ในโฟลเดอร์สำรองที่ตัวอัปเดตแจ้ง จากนั้นเปิด START.cmd ของโปรแกรมเดิม

## เครื่องใหม่หรือใช้แพ็กเต็ม

1. แตก ZIP ลงโฟลเดอร์เขียนไฟล์ได้ แยกจากโปรแกรมเดิม
2. ติดตั้ง Python 3.12 64-bit ตัวเปิดค้นหา Launcher, PATH, Registry และโฟลเดอร์ทั่วไปได้ แต่ไม่ติดตั้ง Python ให้เอง
3. ติดตั้ง NVIDIA driver สำหรับงานถอดเสียง/จับเวลาบน GPU หรือเลือกตัวถอด CPU ที่รองรับในโหมดทำซับ
4. เชื่อมต่ออินเทอร์เน็ต เปิด START.cmd โปรแกรมเตรียม .venv/ไลบรารีเมื่อจำเป็น หรือเปิด SETUP.cmd แยก
5. รอเว็บเปิด ปกติ http://127.0.0.1:8776/ ถ้าพอร์ตไม่ว่าง ตัวเปิดจะเลือกพอร์ตและเปิดหน้าที่ถูกต้อง
6. ใส่ API key ของผู้ใช้ เลือก XML และเตรียมสื่อให้ครบ หากย้ายพาธใช้ช่อง relink ใน PRO

หากค้นหา Python ไม่พบ ตั้ง INWOUM_PYTHON เป็นพาธเต็มของ Python 3.12 64-bit ได้ ไม่ต้องย้าย .venv จากอีกเครื่อง โมเดลที่ยังไม่มีจะดาวน์โหลดครั้งแรก

## การตัดต่อและตัวเลือก

- คลิปขายของ: FULL และคลิปย่อย ทุกคลิปไม่เกิน 3 นาที
- คลิปเดียว: ตามลำดับเดิมหรือ AI เรียบเรียง เลือกความยาวไม่จำกัด/ไม่เกิน 3 นาที
- Default: ต่อเรื่องเป็นชุดเหตุการณ์ รักษาบริบทและลำดับสาธิต ไม่ยืมคำโดดมาเติมประโยค ตรวจจากข้อความ ยังไม่ดูภาพ
- Original: วิธีตัดเดิม คำสั่งและผลขอบตัดตรวจเทียบรุ่นก่อนแล้ว งานเก่าที่ไม่มี style คงวิธีเดิมเมื่อทำต่อ
- Default ลดคัทสั้นด้วยการต่อคำที่เลือกติดกัน และเชื่อมพักสั้นภายในท่อนที่เลือกเท่านั้น ไม่ข้ามคำที่ตั้งใจตัด เชื่อมได้ไม่เกิน 0.24 วินาทีต่อจุด คืนช่วงพักรวมไม่เกิน 0.4 วินาทีต่อเวอร์ชัน ไม่ลบพยางค์เพื่อซ่อนคัทสั้น
- Default ใส่ audio crossfade 40ms เมื่อมี media handle พอ ไม่เลื่อนภาพ เสียงพรีวิวมี crossfade ด้วย
- การจัดเหตุการณ์ใช้ API รอบเดิมเป็นหลัก หากพบปัญหาจริงอาจมีคำขอแก้เฉพาะเวอร์ชันเพิ่ม 1 ครั้ง งานเดิมต้องเรียบเรียงผ่าน API ใหม่เพื่อใช้กฎเหตุการณ์รุ่นใหม่ ส่วนปรับจังหวะคัทจากแผนเดิมใช้ปุ่มสร้าง XML ใหม่ ไม่เรียก API
- SRT: CapCut, Whisper GPU และ whisper.cpp CPU ตามตัวเลือก ไม่ใช้ OpenAI เรียบเรียงซับ ตัวเชื่อม CapCut เป็นของชุมชน ไม่ใช้สิทธิ Premium และไม่รับประกันฟรีต่อเนื่อง
- Super: สรุปใจความเป็น text บรรทัดเดียวแก้ได้ใน Premiere ใช้ Kanit Bold ติดตั้งฟอนต์จาก web/fonts/Kanit-Bold.ttf แล้วเปิด Premiere ใหม่
- NOOB/PRO, GPT 6.1 Sol/GPT 6 Luna, ระดับการคิด, token, USD, ความคืบหน้า และธีมยังมีครบ

## ไฟล์งานและการตรวจ

- รองรับ XML Sequence 50fps ตามรูปแบบที่โปรแกรมตรวจรับ ฟุตเทจยังต้องอยู่หรือ relink ให้ถูก
- งานอยู่ใน jobs การลบรายการประวัติไม่ลบไฟล์งาน
- EPISODE-CONTINUITY.md แสดงเหตุการณ์และข้อความที่เลือกจริงในงาน Default รุ่นใหม่
- USD เป็นประมาณการจาก usage งานเรียบเรียง ไม่ใช่ยอดรวมบัญชี
- แพ็กนี้ไม่มี API key ฟุตเทจ งานส่วนตัว ประวัติแชต .venv หรือโมเดลของผู้พัฒนา
- key ที่กดบันทึกอยู่ในเบราว์เซอร์เครื่องนั้น ผู้ใช้เบราว์เซอร์ร่วมกันเปิดดูได้
- รวมตัวแก้ค้นหา Python, ตรวจ/ซ่อม PyAV, ขอบ phrase, media reference ใน XML และอัปเดต Default ก่อนหน้าครบ

ดู QA-TEAM.json สำหรับหลักฐานและขอบเขตการทดสอบ ต้องฟังรอยต่อและตรวจนำเข้า Premiere ก่อนส่งงานจริง รอบนี้ยังไม่ได้ยืนยันการนำเข้าบน Premiere เครื่องทีม ตัวเลขเตือนซิงก์สีแดงที่เคยรายงานยังไม่ได้แก้ในรุ่นนี้ จึงไม่ควรกดแก้ซิงก์อัตโนมัติจากตัวเลขเพียงอย่างเดียว


## แก้ตัวตรวจลำดับเรื่อง 0.13.6

ตรวจลำดับตามการเล่าเรื่องใน event.unit_ids แทนการบังคับให้เวลาต้นฉบับเดินหน้า การย้ายท่อนอธิบาย/ผลลัพธ์จากเทคก่อนหน้าจึงใช้ได้เมื่อบริบทถูกต้อง ยังตรวจเรื่องแทรก ขาดบริบท และลำดับเรื่องผิดอยู่ Original คงเดิม

งานคลิปเดี่ยวที่หยุดเพราะกฎเวลาเดิมสามารถตรวจคำตอบ API ที่บันทึกครบและใช้ต่อได้โดยไม่เรียก API เพิ่ม หากข้อความ/การตั้งค่าไม่ตรงหรือสถานะคำขอไม่แน่นอน โปรแกรมจะไม่กู้หรือส่งซ้ำอัตโนมัติ ทดสอบจากข้อมูลทีมโดยไม่แก้หรือส่งออก XML งานทดลอง

0.13.6: Default รวมรหัสท่อนอ้างอิงซ้ำในรายการแผนโดยคงลำดับแรก ไม่เปลี่ยนคำ ลำดับเรื่อง หรือคัทจริง ใช้คำตอบแผนเดิมได้โดยไม่เรียก API ซ้ำ ขั้นเรียบเรียงถัดไปยังมีค่า API ตามปกติ Original คงเดิม


## 0.13.7 — เก็บโครงสร้างเสียงต้นฉบับใน Default

Default ในโหมดขายและคลิปเดี่ยวใช้เสียงแทร็ก 1 วิเคราะห์ แต่คงทุกแทร็กเสียง สถานะเปิด–ปิด ระดับเสียง และความสัมพันธ์ลิงก์ตาม XML ต้นฉบับ แล้วคัทและย้ายตามภาพ ไม่มี crossfade และไม่เพิ่ม marker ข้อมูลการใช้ฟุตและเหตุผลยังอยู่ในรายงาน

แก้จำนวนท่อน Hook หลังลบวลีซ้ำ ตัดนับเตรียมถ่ายเฉพาะที่แยกจากประโยคจริงได้ตามเวลาคำ ไม่ลบตัวเลขทางเทคนิคหรือคัทสั้นทุกชิ้นแบบเหมารวม กฎ Default รักษาคำขายจากต้นฉบับ เช่น ดีที่สุดในโลก/ดีมากมาก ห้ามแต่งคำขายหรือทำคำกล่าวอ้างแรงขึ้นด้วยการตัดบริบท ไม่มีรอบ API เพิ่มโดยอัตโนมัติ Original และโหมดซับ/Super คงเดิม

งานเก่าสามารถคืนทุกแทร็กจาก XML ต้นฉบับเมื่อทำต่อหรือสร้าง XML ใหม่ โดยตรวจต้นฉบับและ cache ก่อน ไม่ถอดเสียงซ้ำเพียงเพื่อคืนแทร็ก ไฟล์ที่ส่งออกไปแล้วไม่ถูกแก้เอง คำตอบ AI ที่เก็บไว้ยังเป็นคำตอบจากกฎเดิม การใช้คำตอบเดิมไม่ใช่การให้ AI เลือกคำขายที่ตกหล่นใหม่

ทดสอบอัตโนมัติ 301 รายการ ไม่มี paid API รอบนี้ ยังไม่ได้ยืนยันการนำเข้าและเลขเตือนซิงก์ใน Premiere เครื่องทีม


## 0.13.8 — ตัด Dead Air ในเครื่อง ไม่ใช้ token

เลือกเมนู ตัด Dead Air > เลือก XML ต้นฉบับหรือ XML ที่ตัดแล้ว > กดตรวจไฟล์และเลือก Sequence > เลือกความกระชับ > เริ่มตัดในเครื่อง ไม่ต้องใส่ API key รองรับ 50 fps ไม่มี nested/multicam/speed หรือ transition ทั่วไป รองรับคืนเฉพาะ crossfade 2 เฟรมจากโปรแกรมรุ่นก่อนเป็นคัทตรง

อ่านเฉพาะเสียงแทร็ก 1 ใช้ VAD และความดังร่วมกันในเครื่อง ไม่ถอดข้อความ ไม่ใช้ CapCut/OpenAI ไม่เรียงเรื่องหรือเกลาคำตามความหมาย เก็บทุกแทร็กและลิงก์เดิม ส่งออกไฟล์ใหม่

การคืนขอบเสียงทำเฉพาะช่องว่างไม่เกิน 0.12 วินาทีในสื่อเดียวกัน ทุกแทร็กต้องมีขอบพร้อมกันและมีเสียงจริงให้คืน จะไม่สร้างคำหรือเดาคัทต่างเทค การรวมคัทซ้ำซ้อนทำเฉพาะคลิปที่ไม่มีลิงก์ รวมถึงไม่มีคลิปอื่นลิงก์เข้ามา สื่อและเอฟเฟกต์เหมือนกันและเวลาต้นฉบับต่อเนื่อง คัทสั้นที่ยังมีเสียงไม่ถูกลบทิ้งตามความยาวอย่างเดียว ดูรายงานคัทจาก XML ที่ส่งออกแล้วฟังตรวจ

ทดสอบรวม 315 รายการ มีการทดสอบตัวตรวจเสียงพูดจริงโดยปิดกั้นเครือข่าย และกดจาก UI ถึงผลลัพธ์/ดาวน์โหลด ไม่มี paid API รอบนี้ ยังไม่ได้ตรวจฟังคำพูดจริงหรือยืนยันการนำเข้า Premiere เครื่องทีม


0.13.9: แก้การเขียน XML ชั่วคราวให้ใช้ชื่อ encoding UTF-8 ตามมาตรฐาน รองรับชื่อ Sequence และโฟลเดอร์ภาษาไทย ทดสอบ 316 รายการ ไม่มีการเรียก API เพิ่ม


## 0.14.0 — Default 02 เป็นค่าเริ่มต้นของงานใหม่

ทั้งโหมดขายของและคลิปเดี่ยวมีสามตัวเลือก: Default 02 เกลาคำและจังหวะละเอียด, Default วิธีต่อเรื่องเดิม, Original วิธีดั้งเดิม งานเก่าที่ยืนยันตัวเลือกเดิมไว้ยังใช้วิธีเดิม การเปลี่ยนไป Default 02 ให้สร้างงานเรียบเรียงใหม่จากข้อความเดิม ไม่ใช้ผลเก่ามาอ้างว่าเกลาใหม่แล้ว

Default 02 อนุญาตตัดคำเกริ่นซ้ำและวลีเกินจำเป็นภายในท่อนเดิม แล้วต่อช่วงที่เหลือตามลำดับเดิม ไม่ยืมคำโดดต่างเทค เก็บ Hook/อารมณ์ขาย/คำเน้นและเงื่อนไข ไม่ใช้โควตาระยะเวลาหรือจำนวนคัท กรองเฉพาะเศษ padding ไม่เกิน 0.1 วินาทีที่ไม่มีทั้งขอบคำที่เลือกและ VAD เสียงพูดรองรับ ไม่ลบคำสั้นที่มีความหมาย

ในคลิปเดี่ยว วิธีตามลำดับเดิมยังรักษาการเลือกท่อนเต็มตามเดิม ให้เลือกวิธีเรียบเรียงเมื่อต้องการเกลาคำภายในท่อน คำสั่งเกลาใช้ในคำขอประกอบบทเดิม ไม่มีขั้น API ใหม่ แต่ token ในคำขออาจเพิ่มตามคำสั่ง ไม่รับประกันราคาหรือผลลัพธ์เท่าเดิมทุกคลิป

ทดสอบ 326 รายการ รวมการเทียบ hash คำขอ Default เดิมและ Original กับโปรแกรม 0.13.9 และทดสอบทั้ง pipeline ด้วยคำตอบจำลอง ไม่มี paid API รอบนี้ คุณภาพการเกลาจาก API จริงยังต้องทดสอบ
