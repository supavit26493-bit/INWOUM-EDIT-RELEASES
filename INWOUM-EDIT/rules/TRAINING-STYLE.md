# คำชี้แจงสไตล์ล่าสุด — ทีม v1.0.1

วันที่17ตุลาคม2026 ที่มา:ผู้ใช้ชี้แจงโดยตรงหลังดูTEST07ที่ตัดใหม่และตัวอย่างEX07 คำสั่งนี้เหนือข้ออนุมานAIในรายงานEX07/TEST07ก่อนหน้า

## เป้าหมายคลิปขายของ

Hookต้องดึงดูดคนดู ใช้pain point ความกลัว และคำพูดเวอร์เชิงขายได้ตามบริบท ไม่ต้องเกลาจนเหลือแต่รีวิวเป็นกลาง ทำหลายแนวให้เลือกได้ ไม่ทิ้งHookทั้งหมดเพราะคำใกล้เคียงมีส่วนที่ควรตัด

ผู้ใช้อนุญาตตัวอย่างชัดเจน:

- “ไปยุโรปหรือไปต่างประเทศ คุณอย่านิ่งนอนใจนะครับ หมดตัวเลยนะ”
- “สิ่งที่น่ากลัวที่สุดสำหรับยุโรปนะ คือโดนล้วงง่ายมากแบบนี้”
- จังหวะดึงสายโชว์พร้อม “แข็งแรงอยู่แล้ว แล้วมีลวดอยู่ข้างในอีกเส้นนึง” ให้พิจารณาเก็บทั้งคำและแอคชั่น เป็นการแสดงคุณสมบัติ ไม่ตัดหมดเพราะมีคำว่าแข็งแรงย้ำ

ประโยคที่เตือนความเสี่ยงตามสถานการณ์/พื้นที่ไม่ถูกตัดเพียงเพราะมีความกลัวหรือเอ่ยยุโรป คำหยาบ/เหยียดคนยังใช้กติกาเดิม ไม่สร้างตัวเลขผลวัด เหตุการณ์สาธิต หรือหลักฐานรับรองที่ไม่มีในsourceจากคำอนุญาตโทนขายนี้

## ราคา

เกณฑ์ใหม่แทนคำสั่งเดิมที่ตัดทุกคำว่า“ราคา”:

- ใช้ได้:ราคาถูกมาก ราคาถูก ราคาไม่แพง ราคาเข้าถึงได้ คุ้มราคา/ราคาคุ้มค่า เมื่อไม่มีจำนวนเงินตรงๆ
- ยังตัด:จำนวนเงินตรงๆ บาท หลักร้อย หลักพัน หลักหมื่น ตามเกณฑ์ผู้ใช้เดิม
- คำแทนธนบัตรที่อนุญาต เช่น1ใบเทา2ใบแดงยังใช้ได้
- เป็นเกณฑ์ผลิตของผู้ใช้ ไม่ใช่ข้อรับรองนโยบายTikTok

## ใช้ทุกงานถัดไป

### คำตอบเพิ่มเติมจากผู้ใช้17ตุลาคม2026

**แก้ข้อ4ล่าสุด:**ผู้ใช้ไม่ต้องการเสียงที่ถูกปิดเลย ถ้าต้องปิดเสียงให้ตัดท่อนนั้นออกทั้งภาพและเสียง หรือเก็บพร้อมเสียงเดิม ห้ามmute/Disable/gainจนเงียบ/WAVศูนย์ ข้อนี้แทนคำแนะนำเรื่องปิดเสียงเฉพาะช่วงทั้งหมดก่อนหน้า
- เทคชัด/กระชับและเทคอารมณ์ขายดี:ผู้ใช้ขอทั้งสองแบบ ให้สร้างตัวเลือกจากทั้งสองแนวเมื่อใช้ได้จริง ไม่ต้องเลือกเพียงแบบเดียวแทนผู้ใช้
- Hookต่างกันแต่กลาง/ท้ายเหมือนกัน:ผู้ใช้อนุญาตและขอทำทุกแบบที่มีHookหรือเทคใช้ได้จริง ไม่ต้องบังคับให้เนื้อหากลางต่างกันด้วย ไม่สร้างการเรียงสับเปลี่ยนไร้หน้าที่เพิ่มจำนวน
- พูดไม่ครบ:ลองเรียงท่อนอื่นให้จบความได้ก่อน หากเข้าใจและความหมายตรงใช้ได้ ถ้าพูดทิ้ง/ค้างจนไม่จบความ ไม่ต้องใช้ ไม่จำเป็นต้องส่งSequenceรอเติมทุกท่อนที่ไม่สมบูรณ์
- เสียงหลังกล้อง/เสียงไม่ชัด:ไม่ต้องฝืนเก็บ ผู้ใช้ไม่ถือว่าสำคัญมาก ตัดคำแทรกหรือท่อนนั้นและรักษาคำพิธีกรที่เล่าเรื่องได้ด้วยตัวเอง อย่าให้คำตอบลอยเพราะตัดคำถามออก ไม่ตีความเป็นmuteทั้งช็อตสาธิตจนเสียงใช้งานหาย

ก่อนตัด ทำHookinventoryแยกprepared hook / pain pointหรือความกลัว / จุดเด่น / ผลหรือปฏิกิริยา แล้วเลือกที่รองรับเนื้อหา ทำแบบภาพรวมและแบบมุมต่างกันตามสาระ ไม่บังคับจำนวนเวอร์ชัน ทบทวนเหตุไม่ใช้Hookว่ามาจากคำสั่งผู้ใช้หรือการระวังเกินไปของAI

ตรวจคำซ้ำตามหน้าที่ ประโยคแข็งแรง+มีลวดเพิ่มข้อมูล/แรงขายจึงไม่ใช่ย้ำไร้สาระโดยอัตโนมัติ ส่วน“ดีมาก ดีมาก”ติดกันโดยไม่มีหน้าที่ยังเกลาตามกติกาเดิม

ต้นคลิปไม่มีdead air,เกลาช่วงรอภายในtest,jump cutได้,เก็บหัวท้ายคำและเสียงใช้งานเดิม,ไม่muteทั้งช็อตเพื่อทิ้งคุยทีม,ตรวจหลังประกอบและฟังจริงยังคงใช้ครบ
