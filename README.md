# INWOUM EDIT

ซอร์สโปรแกรมเวอร์ชัน **0.15.22** และชุดอัปเดตสำหรับทีม

## ดาวน์โหลด

ดาวน์โหลดไฟล์จาก [Release ล่าสุด](https://github.com/supavit26493-bit/INWOUM-EDIT-RELEASES/releases/latest)

- `TEAM.zip`: ติดตั้งเครื่องใหม่
- `UPDATE.zip`: อัปเดตเครื่องเดิมที่ยังไม่มีปุ่มอัปเดต
- `update.json`: ข้อมูลพร้อมลายเซ็นสำหรับปุ่มอัปเดต ไม่ต้องเปิดเอง

## เปิดได้สองแบบ

หลังตั้งค่าสภาพแวดล้อมด้วย SETUP.cmd ในโฟลเดอร์ INWOUM-EDIT:

- `START-APP.cmd` เปิดหน้าต่างแอปเดสก์ท็อปบน Windows
- `START-WEB.cmd` หรือ `START.cmd` เปิดแบบเว็บ

ทั้งสองแบบใช้ระบบและโฟลเดอร์งานเดียวกัน ไม่เปิดเซิร์ฟเวอร์ซ้ำ
ส่วนหน้าต่างติดตั้งเมื่อเปิดแอปครั้งแรกและต้องมี Microsoft Edge WebView2 Runtime
ธีมและ API key ของแอปเก็บแยกจากเบราว์เซอร์ ต้องใส่ key ในแอปครั้งแรก
ดู [คู่มือเดสก์ท็อป](INWOUM-EDIT/DESKTOP.md)

## ซอร์ส

โค้ดใน [INWOUM-EDIT](INWOUM-EDIT) ตรงกับ SHA-256 ใน INSTALL-MANIFEST.json ของชุดที่เผยแพร่
ใช้ประวัติ Commits เพื่อดูการเปลี่ยนแปลงและย้อนดูโค้ดแต่ละรุ่น
สำหรับแจกใช้งานให้ใช้ไฟล์แนบใน Releases แทน Source code ZIP อัตโนมัติ

ไม่รวมงานตัดต่อ ฟุตเทจ API key, .venv, โมเดล การตั้งค่าเฉพาะเครื่อง และกุญแจส่วนตัวผู้เผยแพร่
ไฟล์ tests/update-test-key.xml เป็นกุญแจจำลองสำหรับทดสอบ ไม่ใช่กุญแจผู้เผยแพร่จริง
