# INWOUM EDIT

ซอร์สโปรแกรมเวอร์ชัน **0.15.23** และชุดอัปเดตสำหรับทีม

## ดาวน์โหลด

ใช้ไฟล์แนบใน [Release ล่าสุด](https://github.com/supavit26493-bit/INWOUM-EDIT-RELEASES/releases/latest)

- `TEAM.zip`: ติดตั้งเครื่องใหม่
- `UPDATE.zip`: อัปเดตเครื่องเดิมที่ยังไม่มีปุ่มอัปเดต
- `update.json`: ข้อมูลพร้อมลายเซ็นสำหรับระบบอัปเดต ไม่ต้องเปิดเอง

## เปิดโปรแกรม

หลังตั้งค่าสภาพแวดล้อมด้วย SETUP.cmd ในโฟลเดอร์ INWOUM-EDIT:

- **INWOUMEDIT.exe** ตัวเปิดแอปพร้อมไอคอน
- `START-APP.cmd` ตัวเปิดแอปสำรอง
- `START-WEB.cmd` หรือ `START.cmd` เปิดแบบเว็บ

ทั้งสองแบบใช้ระบบและงานชุดเดียวกัน ไม่เปิดเซิร์ฟเวอร์ซ้ำ
เก็บ INWOUMEDIT.exe ไว้กับไฟล์โปรแกรมเดิม ย้ายทั้งโฟลเดอร์ได้ ไม่ย้ายเฉพาะ EXE
ครั้งแรกของแอปต้องติดตั้งส่วนหน้าต่างผ่านอินเทอร์เน็ตและมี Microsoft Edge WebView2 Runtime
API key กับธีมของแอปเก็บแยกจากเบราว์เซอร์ ต้องใส่ key ในแอปครั้งแรก
ดู [คู่มือเดสก์ท็อป](INWOUM-EDIT/DESKTOP.md)

## ซอร์ส

โค้ดใน [INWOUM-EDIT](INWOUM-EDIT) ตรงกับ SHA-256 ใน INSTALL-MANIFEST.json ของชุดเผยแพร่
ตัวเปิด Windows มีซอร์สที่ launcher/INWOUMEDIT.cs
ใช้ Commits ดูการเปลี่ยนแปลงแต่ละรุ่น สำหรับใช้งานให้ดาวน์โหลดไฟล์แนบใน Releases

ไม่รวมงานตัดต่อ ฟุตเทจ API key, .venv, โมเดล การตั้งค่าเฉพาะเครื่อง และกุญแจส่วนตัวผู้เผยแพร่
ไฟล์ tests/update-test-key.xml เป็นกุญแจจำลองสำหรับทดสอบ ไม่ใช่กุญแจผู้เผยแพร่จริง
