# INWOUM EDIT

ซอร์สโปรแกรมเวอร์ชัน **0.15.29** และชุดอัปเดตสำหรับทีม

## ดาวน์โหลด

ดาวน์โหลดไฟล์แนบใน [Release ล่าสุด](https://github.com/supavit26493-bit/INWOUM-EDIT-RELEASES/releases/latest)

- `TEAM.zip`: ติดตั้งเครื่องใหม่
- `UPDATE.zip`: อัปเดตเครื่องเดิมที่ยังไม่มีปุ่มอัปเดต
- `update.json`: ข้อมูลพร้อมลายเซ็นสำหรับระบบอัปเดต ไม่ต้องเปิดเอง

เครื่องที่มีปุ่มอัปเดตแล้ว กดปุ่มอัปเดตด้านล่างโปรแกรมได้เลย เก็บงาน โมเดล และการตั้งค่าเดิมไว้

## เปิดโปรแกรม

ตั้งค่าสภาพแวดล้อมด้วย `SETUP.cmd` ในโฟลเดอร์ INWOUM-EDIT แล้วเปิด:

- **INWOUMEDIT.exe**: แอปเดสก์ท็อปพร้อมไอคอน
- `START-APP.cmd`: ตัวเปิดแอปสำรอง
- `START-WEB.cmd` หรือ `START.cmd`: เปิดแบบเว็บ

เว็บและแอปใช้ระบบประมวลผลและงานชุดเดียวกัน ย้ายทั้งโฟลเดอร์ ไม่ย้ายเฉพาะ EXE
ครั้งแรกของแอปต้องติดตั้งส่วนหน้าต่างผ่านอินเทอร์เน็ตและมี Microsoft Edge WebView2 Runtime
API key กับธีมของแอปเก็บแยกจากเบราว์เซอร์ ต้องใส่ key ในแอปครั้งแรก
ดู [คู่มือเดสก์ท็อป](INWOUM-EDIT/DESKTOP.md)

## รุ่น 0.15.29

แก้เทคสำรองในโหมดขายของ 2.1 ให้ใช้เนื้อหาจากคลิปหลักได้เมื่อประกอบเป็นอีกมุมขายครบถ้วน ไม่บังคับฟุตเทจใหม่ เทคสำรองที่ไม่ผ่านจริงจะเก็บแผนและเหตุผลแยกไว้ โดยไม่ขวางคลิปหลัก ผ่าน 478 tests และทดสอบทำต่อจากคำตอบเดิมจนส่งออกครบ 4 เวอร์ชันโดยไม่เพิ่ม API

## รุ่น 0.15.28

แก้ขอบคำเริ่มประโยคเดียวกันถูกเลือกซ้ำในคลิปเดี่ยวแบบเรียบเรียง ทำในเครื่องโดยไม่เพิ่ม API และคงลำดับเรื่องเดิม ทดสอบทำต่อจากคำตอบที่เก็บไว้จนส่งออก XML สำเร็จโดยบล็อกเครือข่าย

แก้คำขอซ่อมคำโดดในโหมดคลิปเดี่ยวให้ซ่อมเฉพาะจุด ลดกฎซ้ำที่อาจทำให้ HTTP 400 และแสดงสาเหตุข้อผิดพลาดตรงประเภท ผ่าน 473 tests โดยไม่เรียก API จริง โหมดขายของและ Original คงวิธีเดิม

รวมการปรับหน้าตาจาก 0.15.24–0.15.26: เมนูติดด้านบน เมาส์มาตรฐานระบบ และรายงานท่อนที่ไม่ได้ใช้แบบพับเก็บ

## ซอร์ส

โค้ดใน [INWOUM-EDIT](INWOUM-EDIT) ตรงกับ SHA-256 ใน INSTALL-MANIFEST.json ของชุดเผยแพร่
ตัวเปิด Windows มีซอร์สที่ `launcher/INWOUMEDIT.cs` ดูการเปลี่ยนแปลงแต่ละรุ่นใน Commits

ไม่รวมงานตัดต่อ ฟุตเทจ API key, .venv, โมเดล การตั้งค่าเฉพาะเครื่อง และกุญแจส่วนตัวผู้เผยแพร่
ไฟล์ `tests/update-test-key.xml` เป็นกุญแจจำลองสำหรับทดสอบ ไม่ใช่กุญแจผู้เผยแพร่จริง
